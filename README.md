# Women Techmakers Curitiba

## Site 2025 

Este site foi criado apra substituir o meetup e manter o registro histórico so encontros.

### 🚀 Quick Start
Instalar Tailwind CSS
'npm install --save-dev tailwindcss @tailwindcss/cli'

Executar local  
`npm run dev`

### 🖼️ Template

https://themes.gohugo.io/themes/hugoplate/


### ⚙️ Pré-requisitos

- [Hugo Extended v0.144+](https://gohugo.io/installation/)
- [Node v22+](https://nodejs.org/en/download/)
- [Go v1.24+](https://go.dev/doc/install)


##### Deploy do site

- execute o comando para gerar os arquivos estáticos na pasta `public`.  
`yarn project-setup; yarn build`

- copie o conteúdo da pasta public para o [repositório do site](https://github.com/wtmcuritiba/wtmcuritiba.github.io)

- faça push para a branch master do repositório do site que o deploy acontece automaticamente.
